🚀 5 分钟快速入门

从零到第一次有效对话 — 一步步带你上手 Claude Code

1

安装 Claude Code

⏱ 约 2 分钟

选择你的操作系统，在终端中运行对应命令。

# macOS — 使用 Homebrew brew install claude-code claude login
# Linux — 使用 npm npm install -g @anthropic-ai/claude-code claude login
# 任何系统 — 使用 npm (需要 Node.js ≥ 18) npm install -g @anthropic-ai/claude-code claude login

claude login 会打开浏览器验证你的 Anthropic 账户。完成后回到终端。

2

第一次对话

⏱ 约 1 分钟

进入你的项目目录，启动 Claude，说出你的第一句话。

# 进入项目目录 cd my-project # 启动 Claude Code claude # 👇 你的第一句话（在 claude 提示符下输入） 帮我创建一个 Python 计算器，支持加减乘除
💡 预期效果：Claude 会自动创建 calculator.py 文件，写入完整代码，并向你解释实现逻辑。你会看到它在使用 Read、Write、Bash 等工具。
3

理解三个核心概念

⏱ 约 1 分钟
💬

会话 Session

每次 claude 启动就是一个会话。Claude 记住整个对话上下文，直到你 /clear 清空。

🔧

工具 Tools

Claude 能读文件(Read)、写文件(Write)、运行命令(Bash)、搜索代码(Grep)。这些就是"工具"。

🔐

权限 Permissions

Claude 执行某些操作前需要你同意。你可以选择 Allow（允许）、Deny（拒绝）、或 Always Allow（始终允许）。

🔐 权限级别
Ask → Auto → Bypass
4

记住这 5 个命令

⏱ 约 1 分钟
命令用途什么时候用
/help列出所有命令忘了什么命令时
/clear清空对话历史话题切换、上下文满了
/model切换 AI 模型想用更快/更强的模型
/cost查看 Token 消耗想了解花费了多少
/diff查看所有更改提交前确认改动
