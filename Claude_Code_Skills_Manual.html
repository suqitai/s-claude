💡 什么是 Skill？
技能（Skill）是 Claude Code 的可扩展能力单元。每个技能由一个 SKILL.md 文件定义，包含 YAML 元数据和 Markdown 指令。 内置技能随 Claude Code 一起发布；你也可以创建项目级或用户级的自定义技能，通过 Git 与团队共享。

.claude/commands/

💬 会话与上下文管理

管理对话会话、上下文窗口、历史记录——让长任务不丢失进度。

命令功能说明别名
/clear清空对话历史，释放上下文窗口/reset, /new
/compact [focus]压缩对话历史，保留关键信息；可选 focus 指定保留重点—
/resume [name|ID]恢复之前的会话继续工作/continue
/rename [name]重命名当前会话，方便后续查找—
/rewind回滚对话和代码到上一个检查点/checkpoint
/branch [name]从当前状态创建一个对话分支/fork
/diff打开交互式差异查看器，显示所有待提交更改—
/copy [N]复制第 N 条最近回复或代码块到剪贴板—
/export [filename]导出当前对话到文本文件—
/exit退出 Claude Code/quit
/background将当前会话移至后台运行—
💡 小贴士：当上下文窗口接近上限时，使用 /compact 压缩历史， 或使用 /rewind 回滚到更早的状态再继续。长任务建议配合 /branch 分支探索不同方案。

🎨 自定义技能开发

创建自己的技能，赋予 Claude Code 领域专长。技能通过 Git 共享，团队共同维护。

📁 技能目录结构

.claude/skills/my-skill/
├── SKILL.md          ← 必需：YAML 元数据 + Markdown 指令
├── references/      ← 可选：详细参考文档（按需加载）
│   ├── api-docs.md
│   └── examples.md
├── scripts/         ← 可选：可执行代码（Python/JS）
│   └── helper.py
└── assets/          ← 可选：模板、图片等资源
    └── template.txt
🏠
用户级技能
~/.claude/skills/<name>/SKILL.md

个人使用，所有项目可用。不随 Git 共享。
📦
项目级技能
.claude/skills/<name>/SKILL.md

团队共享，随 Git 提交。项目成员自动加载。

🧬 SKILL.md 结构详解

每个技能的核心文件——YAML 前置元数据 + Markdown 正文指令。

📝 完整示例

---
name: my-deploy                    # kebab-case，最长 64 字符
description: Deploy the project to staging via AWS CDK
argument-hint: [environment]          # 斜杠菜单中的参数提示
disable-model-invocation: false   # true = 只能手动调用
user-invocable: true               # false = 隐藏在 / 菜单
allowed-tools:                       # 无需权限弹窗的工具
  - Bash
  - Read
disallowed-tools:                    # 显式禁止的工具
  - Edit
model: sonnet                       # 可选模型覆盖
context: fork                       # 在隔离子代理中运行
---

# 部署到预发布环境

## 步骤
1. 运行 cdk synth 生成 CloudFormation 模板
2. 运行 cdk deploy 部署到指定环境
3. 等待部署完成并输出 URL

📋 元数据字段参考

字段类型默认值说明
namestring—（必需）kebab-case 技能名，最长 64 字符
descriptionstring—（必需）第三人称描述，最长 200 字符。Claude 用来自动发现匹配的技能
argument-hintstring—在斜杠命令菜单中显示的参数提示
disable-model-invocationbooleanfalsetrue = 仅用户手动 /name 调用，Claude 不自动触发
user-invocablebooleantruefalse = 隐藏在 / 菜单中
allowed-toolsstring[]—使用时无需权限弹窗的工具列表
disallowed-toolsstring[]—显式禁止使用的工具列表
modelstring继承主会话可选模型覆盖：sonnet / opus / haiku
contextstring—fork = 在隔离子代理上下文中运行

🧠 核心概念

📖
渐进式披露
会话启动时只加载名称+描述（~100 tokens）。触发技能时才加载完整 SKILL.md 正文。 参考文档（references/）仅在需要时加载。
🤖
自动调用
Claude 自动扫描技能描述，匹配当前任务时自动加载对应技能。 设置 disable-model-invocation: true 可禁用此行为。
🥇
优先级规则
同名技能：项目级覆盖用户级。Skills（.claude/skills/）优先于旧版 Commands（.claude/commands/）。
🔄
热加载
使用 /skills 列出所有已发现技能；/reload-skills 无需重启即可重新扫描技能目录。

⌨️ 键盘快捷键

掌握这些快捷键，大幅提升操作效率。

快捷键操作场景
Ctrl + C中断当前执行停止正在运行的命令或 AI 输出
Ctrl + D退出 Claude Code结束会话
Esc取消 / 关闭对话框关闭弹窗或退出当前模式
Tab自动补全补全命令、文件路径
↑ / ↓浏览输入历史快速复用之前的命令
Space (长按)语音输入需先启用 /voice
💡 高级技巧：使用 /keybindings 或 /keybindings-help 技能 可以自定义所有快捷键，包括和弦键绑定（chord bindings）。配置文件位于 ~/.claude/keybindings.json。
